Build/Publish
=============

Source of truth for flight_sim is this folder.

Commands:
- `npm run build`
- `npm run build:publish`

This project has no bundling step. The build copies runtime files into `dist/`.
`build:publish` copies `dist/` to:
`C:\Users\sword\offline files\CS\TKosa.github.io\AI Made Projects\flight_sim`
